# Opsis Appearance 1.7.1

## English
- The update popup (Install / Later / Skip this version / What's new, SHA-256 verified, silent install) now also runs when Appearance is loaded as a plugin inside Opsis, plus a "Check for updates..." button and tray-menu entry. In plugin mode the installer runs after Opsis closes.
- Settings are grouped in six category tabs (Theme & colour, Taskbar, Windows, System, Wallpaper & themes, Guide & updates), Greek and English.
- 1.7.0 was published before these changes; this release only adds them (no other change).
- Verified: 232 unit tests, settings tabs rendered in the real window. NOT VERIFIED: the update popup against a real newer release, the installer on a clean/upgraded PC, 150/200 % DPI and RTL. Still open: per-card Reset and settings search.
- Assets with `.sha256`: Setup.exe, Plugin zip, Stand-alone zip.

## Ελληνικά
- Το popup ενημέρωσης (Εγκατάσταση / Αργότερα / Παράλειψη έκδοσης / Τι νέο υπάρχει, SHA-256, σιωπηλή εγκατάσταση) δουλεύει πλέον και όταν το Appearance φορτώνεται ως plugin μέσα στο Opsis, με κουμπί «Έλεγχος για ενημερώσεις…» και εγγραφή στο μενού. Στο plugin ο installer τρέχει αφού κλείσει το Opsis.
- Οι ρυθμίσεις ομαδοποιήθηκαν σε έξι καρτέλες (Θέμα και χρώμα, Taskbar, Παράθυρα, Σύστημα, Wallpaper και θέματα, Οδηγός και ενημερώσεις), ελληνικά και αγγλικά.
- Το 1.7.0 δημοσιεύτηκε πριν από αυτές τις αλλαγές· αυτή η έκδοση προσθέτει μόνο αυτές.
- Ελέγχθηκαν: 232 unit tests, καρτέλες στο πραγματικό παράθυρο. ΔΕΝ ελέγχθηκαν: το popup με πραγματική νεότερη έκδοση, ο installer σε καθαρό/αναβαθμισμένο PC, DPI 150/200 % και RTL. Ανοιχτά: Επαναφορά ανά κάρτα, αναζήτηση ρυθμίσεων.
