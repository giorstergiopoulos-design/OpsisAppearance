# Opsis Appearance 1.3.0

## English
- **Explorer & taskbar behaviour**: file extensions, hidden files, seconds in the clock, window animations, taskbar button grouping, and a Restart Explorer button. Included in the backup/restore of your original values.
- **Wallpaper slideshow**: pictures from a folder every N minutes (shuffle or in order, fit mode), "Next now"; turning it off puts your previous wallpaper back.

**Tests**: 83 unit tests pass. The settings page was rendered to an image to check the layout. The registry writes themselves are covered by fake-registry tests; they were not applied to this PC during testing.

## Ελληνικά
- **Συμπεριφορά Εξερευνητή και taskbar**: επεκτάσεις αρχείων, κρυφά αρχεία, δευτερόλεπτα στο ρολόι, animations παραθύρων, συνδυασμός κουμπιών και κουμπί επανεκκίνησης του Εξερευνητή. Μπαίνουν στο αντίγραφο ασφαλείας των αρχικών τιμών.
- **Wallpaper slideshow**: εικόνες από φάκελο κάθε N λεπτά (τυχαία ή με σειρά, τρόπος προσαρμογής), «Επόμενο τώρα»· όταν το σβήσεις γυρνά το προηγούμενο wallpaper.
